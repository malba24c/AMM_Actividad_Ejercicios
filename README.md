## 📂 Estructura del Proyecto
* `clase0/Ejercicios_Clase.java`: Clase principal que contiene el método `main`, un menú interactivo en bucle (`do-while`) y 8 ejercicios implementados mediante métodos estáticos.

## ⚙️ Descripción de los Ejercicios
El programa permite seleccionar mediante consola cualquiera de las siguientes opciones:

1. **Mostrar mensaje N veces:** Solicita un número `N` e imprime en pantalla `"Módulo ejecutándose"` esa cantidad de veces.
2. **Suma de los N primeros impares:** Calcula y devuelve la suma acumulada de los primeros `n` números impares.
3. **Máximo de dos números:** Compara dos números enteros introducidos por el usuario y muestra cuál es el mayor.
4. **Números entre dos enteros:** Pide dos números enteros, determina cuál es el menor y cuál el mayor, e imprime todos los números comprendidos entre ambos.
5. **Doble de un número:** Recibe un número entero y muestra su valor multiplicado por dos.
6. **Mensaje de error según código:** Evalúa un código numérico (`1`, `2` o `3`) usando una estructura `switch` para mostrar el mensaje de fallo correspondiente (memoria, impresora o disco).
7. **Potencia ($x^n$):** Solicita una base `x` (menor que 50) y un exponente `n` (menor que 10), validando ambos datos antes de calcular la potencia mediante un bucle.
8. **Área o volumen de un cilindro:** Pide el radio, la altura y una opción (`'a'` para área o `'v'` para volumen) para calcular y mostrar el resultado geométrico correspondiente.
